# Depot Assistant

Downloads for Depot Assistant: the server that watches Pallet-Track for a depot, and the tray app staff run on their PCs.

This repository holds releases only. Get the latest installers from the Releases page:

- `DepotServer-Setup.exe`: install once on the depot's always-on PC.
- `DepotAssistant-Setup.exe`: install on each staff PC.

Servers and staff PCs update themselves from these releases.
